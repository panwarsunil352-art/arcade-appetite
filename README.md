## Free publishing
### Option 1 — Netlify
1. Go to https://www.netlify.com/
2. Create a free account.
3. Drag the `arcade-appetite-website` folder into Netlify's deploy area (or upload the ZIP after extracting).
4. Netlify gives you a free public `*.netlify.app` URL.

### Option 2 — GitHub Pages
1. Create a GitHub account.
2. Create a public repository.
3. Upload all files/folders from this project.
4. In repository Settings → Pages, enable Pages from the `main` branch.
5. GitHub gives you a public `*.github.io` URL.

For a first-time user, Netlify is usually the easiest.
